# Драйвер каталога: storybook

Семейство: `drivers.catalog` (выбор в setup-гейте скилла storybook,
ключ — `state.json.drivers.catalog` при наличии машины). Дефолтный
драйвер: индустриальный стандарт — controls, a11y-чек, визуальные
регрессии. Цена — зависимости в целевом проекте.

## Подключение (канон для платформы)

1. Dev-зависимости: `storybook` + `@storybook/react-vite` (Vite-билд
   проекта уже есть — отдельный фреймворк-конфиг не нужен).
2. `.storybook/main.ts` — stories-глобы `../src/**/*.stories.*` (в
   монорепо — с учётом корня проекта), addon-docs/controls/a11y.
3. `.storybook/preview.ts` — импорт `design-system/theme.css` проекта
   (примитивы без проектных токенов бессмысленны) + глобальный
   декоратор `ShellProvider` с AppState-фикстурой для виджетов/страниц.
4. Скрипты: `sb` (dev), `sb:build` (статика).

Нюанс монорепо: токены живут в проекте, примитивы — в ядре; каталог
собирается в проекте и показывает примитивы **в проектных токенах**
(ядро без проекта не рендерится — это ожидаемо).

## Stories

- CSF-формат, файлы рядом с компонентами (`<Component>.stories.tsx`).
- Декораторы по уровням — `references/levels.md`.
- Actions вместо колбэков vm (`fn()` из storybook).

Статус: **каркас** — перед первым реальным запуском дописать:
конкретные версии под React 19, состав аддонов, решение по визуальным
тестам (chromatic vs скриншоты).
