# Драйвер каталога: gallery (встроенный модуль)

Семейство: `drivers.catalog`. Лёгкая альтернатива без единой внешней
зависимости: каталог — обычный модуль приложения, видимый только
в dev/по флагу.

## Концепция

- Модуль `gallery` в реестре проекта (`hidden: true`, включён только
  при dev-флаге/роли) — рендерится штатным `ModuleRenderer`.
- Секции = уровни классификатора; внутри — рендер компонентов с
  фикстурами из сидов (те же правила `references/levels.md`).
- §48-страницы: список vm-фикстур, переключение по клику — каталог
  читается прямо в браузере приложения.

Плюсы: нулевые зависимости, каталог живёт в рантайме приложения
(реальный shell, реальные токены), доступен на деплой-стенде.
Минусы: нет controls/a11y/визуальных тестов; страницу §48 нельзя
«пощупать» аддонами.

Статус: **каркас-заглушка** — дописать перед использованием: структуру
модуля, реестр фикстур (где лежат vm-плюшки), точку входа по флагу.
