# Loading и медиа: скелетоны, фейд-ин, слои загрузки

Приёмы уровня L2 (`references/polish-levels.md`), обкатанные на
u-kon feed (2026-09-25). Две зоны: ожидание данных и загрузка
картинок — в моках обе мгновенны, на транспорте станут заметными.

## Слои загрузки (не конкурируют)

| Слой | Что грузит | Индикатор |
|---|---|---|
| Чанк модуля | JS-бандл секции | ModuleLoader (каркас) |
| Данные | запрос кеша/сервиса | скелетон экрана |
| Шрифты/CSS | критичный рендер | render-blocking CSS + preload |

Слои последовательны: спиннер каркаса не отменяет скелетон данных.
Ценность скелетонов/фейдов проявляется на реальном транспорте; на
моках — проверять временной задержкой в сервисе (listCards + N мс)
и убирать её после проверки.

## Скелетон 1:1 — сетка не прыгает

Геометрия призрака обязана повторять геометрию реальной карточки,
иначе появление данных двигает сетку («маргание» после загрузки):

- **Кап обложки**: тот же maxHeight («не выше контента»), не голый
  aspect-ratio — без капа призрак рос на ~200px выше карточки.
- **Высоты строк — реальные line-box карточки** (замерить живой
  рендер: заголовок 21, текст 18, бейдж 23…), НЕ шаги Tailwind
  (`h-4`/`h-3.5` = 16/14 — мимо line-box на 3–5px на строку).
- **Резерв N строк текста — одной обёрткой** суммарной высоты:
  лишний flex-ребёнок = лишний gap (две строки выдержки отдельными
  детьми стоили +10px).
- **Приёмка числами**: замер призрак vs карточка (высоты, top строк
  сетки до/после загрузки), допуск — единицы px.

Анимация заливки (шиммер): «дыхание» (opacity) + свип света по
`::after` (transform translateX, градиент), `overflow:hidden` клипует
по радиусу; `prefers-reduced-motion` глушит элемент и `::after`.
Тон заливки — семантический токен (`--color-surface-alt`), тот же у
плейсхолдеров картинок: скелетон и плейсхолдер визуально едины.

A11y: контейнер `role="status"` + aria-label текста состояния;
призраки `aria-hidden`.

## Фейд-ин картинок (паттерн FeedImage)

Картинка появляется позже DOM: URL из медиа-стора (IndexedDB → blob)
резолвится кадром позже рендера (useMedia), битмап — ещё позже;
белая вспышка → «выпрыгивание». Паттерн:

- span-обёртка владеет геометрией (aspect/высота/радиусы) + заливкой
  bg-surface-alt; img внутри — `size-full object-cover` +
  `transition-opacity`.
- **Заливка на обёртке, фейд на img**: opacity на самом img погасил
  бы и его собственный фон — плейсхолдер обязан переживать фейд.
- Готовность: `onLoad` + `img.complete` в `useLayoutEffect` (dep —
  src): кэшированные картинки и StrictMode-ремоунт завершаются до
  подвеса обработчика — иначе застревают в opacity-0; смена src
  перезапускает фейд.
- `decoding="async"`; ниже фолда — `loading="lazy"`.

## Мутации и анимации от производного стейта

- **Микро-поп (лайк)**: анимация от производного значения. При
  мутациях с перечиткой (оптимистичный override + invalidate) поп —
  только через useEffect с prev-сравнением: render-фаза (паттерн
  Chip) теряется, когда клик порождает два апдейта подряд — рендер
  между ними абортится и очередь render-setState отбрасывается.
- **Инвалидация не перемонтирует вьюху**: `invalidate(prefix)` гасит
  кеш на кадр → экран падает в loading и ремоунтится (умирает
  локальный стейт: поп, фокус, скролл). Лечение —
  stale-while-revalidate: ref-стэш последней записи по ключу (запись
  в рендере, идемпотентна), эффективное значение из стэша, пока
  перечитка в полёте.

## Грабли (живые прогоны)

- **Tailwind v4 молча не эмитит утилиту с несуществующим токеном**
  (`bg-surface-alt` без `--color-surface-alt` в @theme): класс в
  разметке есть, стиля нет, сборка не ругается. Верифицировать
  computed-стиль, не наличие класса в JSX.
- `CSSStyleDeclaration.getAnimationNames` нет в Chromium — живые
  анимации спрашивать `el.getAnimations()` (Web Animations API).
- `page.screenshot` может таймаутиться на дев-сервере (fonts
  waiting) — геометрию и стили проверять computed-пробами;
  скриншот — артефакт ревью, не инструмент проверки.
- Моки мгновенны (LS): скелетон/фейд не увидеть без искусственной
  задержки — вставлять временно в сервис, убирать после проверки
  (не коммитить).
- В headless-пробах transition замирает при удержании `mouse.down()`
  (:active): computed показывает стартовое значение, будто правило
  не применилось — каскад при этом в порядке. Конечные состояния
  вида (hover/active/focus) проверять с инжектом `transition: none
  !important` на время пробы — значения читаются мгновенно и без
  обмана; инжект снимать после.
