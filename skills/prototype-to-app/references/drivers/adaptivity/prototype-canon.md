# Драйвер адаптивности: prototype-canon

Семейство: `drivers.adaptivity` (выбор по `state.json.drivers.adaptivity`).
Подключается в фазах design-system (шаг 2a) и hardening (§48-аудит) в
точках `<!-- L2: drivers.adaptivity -->`.

## Назначение

Случай «источник — десктопный прототип, приложению нужна мобильная
поддержка». Принцип: **десктоп переносится 1:1 по канону прототипа;
мобильная раскладка — производная канона** (те же токены, компоненты и
геометрия, другие контейнерные правила), а не редизайн. Всё, что
добавляется сверх прототипа (бургер-меню, столбцовые шапки),
фиксируется D-записью — это новый канон, не «улучшение».

## Правила раскладки (отсечки по возрастанию ширины)

- **Брейкпоинты двух сортов.** Контентные — из `@media` прототипа
  (например 1080px → ближайший `lg` 1024, допуск — D-записью);
  телефонные — платформенные `md` 768 / `lg` 1024 (topbar-элементы,
  шапки экранов, навигация). Не «по умолчанию md» для контента.
- **Grid-item'ы обязаны уметь сжиматься.** `.grid > * { min-width: 0 }`
  в `@layer components`: auto-трек страницы растягивается до
  min-content самого широкого item'а (таблица `min-width:560`
  растягивала карточки до 679px и всю страницу на +279px). Широкая
  таблица при этом скроллится внутри своей scroll-обёртки
  (`.table-wrap { overflow-x: auto }`) — обёртка не защищает от
  растяжения трека, защищает только `min-width: 0` на item'е.
- **Компонентные классы — только в `@layer components`.** Unlayered
  (top-level) правило перебивает utilities **всех** слоёв: `hidden
  md:flex` на элементе молча перестаёт работать (урок: `.topsearch`
  вне слоя держал поиск видимым на мобиле и растягивал topbar до
  392px на каждой странице). Утилита должна всегда иметь право
  выиграть.
- **Шапка экрана ниже md — столбец.** Тулбар `flex-none` в строке
  отжимает заголовок (`min-w-0`) в посимвольный перенос (замеряли
  23px ширины) и вылезает за контейнер. Рецепт: `@media
  (max-width: 767px) .phead { flex-direction: column;
  align-items: stretch }`, тулбару — `flex-wrap` (кнопки
  переносятся, а не выпадают). Шапки карточек (`.card-head`) с
  узкими чипами можно не трогать — проверяй запас числами.
- **Навигация ниже lg — бургер.** Контент сайдбара выделяется в один
  `SidebarContent` для десктоп-колонки и мобильной fixed-панели
  (выезд слева, transform+visibility, затемнение). Гигиена дровера:
  закрытие по фону / Escape / выбору раздела; блокировка body-скролла
  на время открытия; `matchMedia(lg)` сбрасывает состояние при
  возврате на десктоп (иначе останется заблокированный скролл).
  `aria-expanded` на бургере.

## Методика аудита (числами, не скриншотами)

Прогон dev-browser'ом по всем маршрутам × ширины {320, 390, 416}:

1. **Критерий чистоты**: `document.documentElement.scrollWidth ==
   clientWidth` на каждом маршруте. Контент внутри scroll-обёртки
   шире вьюпорта — норма (скроллится), не перелив.
2. **Детерминированные ожидания.** Ждать контент-селектор (например
   `.table-wrap tbody tr`) перед замером: моки грузятся асинхронно,
   и проба «сразу после goto» даёт ложно-отрицательное «чисто».
3. **Диагностика форсера ширины** (когда перелив найден):
   - «ребёнок шире родителя» **не работает** при grid-растяжении —
     по цепочке все ≤ родителя; спускайся от `body` по «самому
     широкому ребёнку» до листа-форсера;
   - у обрезанного скроллом контента `rect` выходит за вьюпорт —
     это ложное срабатывание, фильтруй по scrollable-предку;
   - viewport dev-browser скейлится (запрошено 340 → фактических
     378): ориентируйся на фактический `clientWidth`, не на
     запрошенное число.
4. Скриншоты — артефакт для ревью пользователя (fullPage по
   маршрутам), не инструмент проверки геометрии.

## Выход

Отчёт «маршрут × ширина → ok/перелив Npx», скриншоты, D-запись на
каждое применённое правило с consumers (фазы/модули, которые
наследуют правило автоматически).

## Статус

Рабочая конвенция: обкатана на partner-portal (D-026…D-029 —
брейкпоинты из @media, grid-item'ы, слои CSS, столбцовые шапки,
бургер-навигация). Для тестирования альтернативы (например
mobile-first источника) создайте параллельный файл в этом семействе
(см. styling/css-modules.md) и переключите ключ в state.json.
