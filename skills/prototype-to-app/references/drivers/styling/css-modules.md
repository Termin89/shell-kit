# Драйвер стилизации: css-modules

Семейство: `drivers.styling`. Заглушка-альтернатива для проверки
механики L2-драйверов: смена одного ключа в state.json меняет
стайлинг-конвенции всех фаз, не переписывая их.

## Конвенции (набросок)

- Компонент = папка `Component/index.tsx + module.css`; классы —
  camelCase, композиция через `composes`.
- Токены потребляются только css-переменными дизайн-системы;
  raw hex/px — так же запрещены, как в tailwind-драйвере.
- Классы-модификаторы вместо условных утилит
  (`.card.danger` вместо `tone === "danger" && "bg-red-…"`).

Статус: **каркас-заглушка**. Дописать перед первым реальным
использованием: правила для блоков/страниц, точное следование
прототипу (аналог произвольных значений), сигналы для refactor.
