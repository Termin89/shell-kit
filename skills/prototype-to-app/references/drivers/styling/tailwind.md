# Драйвер стилизации: tailwind

Семейство: `drivers.styling` (выбор по `state.json.drivers.styling`).
Подключается в фазах design-system / skeleton / modules.map в точках
`<!-- L2: drivers.styling -->`.

## Конвенции

- Компоненты стилизуются утилитарными классами на **семантических
  токенах**; raw hex/px в компонентах запрещены — всё через токены
  дизайн-системы.
- Примитивы — каркасный класс + минимум утилит; блоки/виджеты/страницы —
  только утилити (без собственных css-файлов).
- Допустимы произвольные значения (`p-[22px]`) для точного следования
  прототипу, но повторяющиеся значения — кандидат в токен (сигнал 4
  фазы refactor).

`<!-- L3: пример -->`
```tsx
<Card className="flex cursor-pointer items-center gap-3 p-[22px]">
```
`<!-- /L3 -->`

## Ловушки Tailwind v4 (v3-мышление ломает вёрстку; уроки прогонов)

- **`leading-<число>` — spacing-шкала, не множитель.** `leading-1.5` →
  `calc(var(--spacing) * 1.5)` = **6px** при `--spacing: 0.25rem` —
  весь текст схлопывается. Безразмерный множитель — только скобки:
  `leading-[1.5]` → `line-height: 1.5`. Проверяй все `leading-*`
  в сгенерированном коде (частое место — `@apply` в theme.css).
- **Брейкпоинт выбирается по числу из `@media` прототипа**
  (например 1080px → `lg` 1024), а не «по умолчанию md».
- **Динамическая spacing-шкала.** `p-13`, `gap-18`, `mt-px` валидны
  (любое число × 0.25rem) — геометрия прототипа переносится точно,
  без округления до стандартных ступеней v3.

Статус: рабочая конвенция (переносится из prototype-to-react без
изменений). Для тестирования альтернативы создайте параллельный файл
в этом семействе (см. css-modules.md) и переключите ключ в state.json.
