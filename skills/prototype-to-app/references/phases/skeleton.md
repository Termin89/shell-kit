# Фаза: skeleton

Статус: каркас. Реентерабельность: да (добавляет отсутствующие модули,
не трогает существующие).

## Назначение

Каркас приложения целиком: все модули зарегистрированы пустыми
заглушками, layout кликается от конца до конца. Ценность — ранняя
проверка таблицы модулей и навигации до вложения в дизайн-систему и
домены. Ширина раньше глубины.

## Вход

- `state.phase == "skeleton"`; артефакт `artifacts/modules-registry.md`.

## Наводящие вопросы (дефолты)

- **Q1 Вид заглушки?** Дефолт: платформенный StateCard-стаб с названием
  модуля и подписью «в разработке» — заглушка сразу на примитивах DS,
  чтобы каркас нёс визуальный словарь. `<!-- L3: пример заглушки -->`
- **Q2 Навигация по прототипу или по реестру?** Дефолт: по реестру
  (модули = навигация прототипа); расхождения — вопросом к
  shell-decisions (reopen), не молчаливой правкой.

## Действия

1. Проба ФС: существующие модули, конфиг shell (что уже есть).
2. Для каждого модуля реестра — пустой модуль по канону платформы:

```ts
// <!-- L3: канонический пример defineModule-заглушки -->
import { defineModule } from "<платформа>";

export default defineModule({
  id: "requests",
  route: "requests",
  enabled: ({ user }) => user.role === "client",
  load: () => import("./pages/RequestsPage"),
});
```

3. Страница-заглушка + строка навигации (иконка, лейбл, маршрут,
   доступ).
4. Прогнать приложение: все маршруты открываются (браузером, см.
   скилл dev-browser), F5 на глубокой ссылке работает (если Q1
   shell-decisions = url-роутинг).

## Выход

- Артефакт: код каркаса (модули-заглушки + навигация).
- state.json: `phase → "design-system"`.

## Гейт

Тривиальный по форме, обязательный по сути: пользователь протыкает
каркас сам («кликается всё? границы модулей верны?»). Изменения границ =
reopen D-записей shell-decisions (см. state-contract.md).

## Изоляция записи

- Разрешено: папки модулей-заглушек, реестр модулей/навигация shell.
- Запрещено: design-system/, shared/, сервисы (кроме пустых
  интерфейсов-заглушек), state.json вне дифа фазы.
