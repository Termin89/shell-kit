# Проектный слой скиллов

Каскад для скиллов платформы: у любого проекта на shell-kit могут быть
свои нюансы и свои доработки скиллов. Правило то же, что в CSS —
проектный слой приоритетнее платформенного.

## Резолв скилла (для агента в проекте)

1. `<проект>/skills/<skill-name>/SKILL.md` — проектный слой
   (оверрайд/расширение).
2. Платформа (база), первый сработавший: монорепо —
   `<root>/skills/<skill-name>/SKILL.md`; плагин — сиблинги папки
   этого скилла (`../<skill-name>/SKILL.md`); фолбэк —
   `node_modules/shell-kit/skills/<skill-name>/SKILL.md`.

Нет проектного — работает платформенный. Оба читаются по одному
контракту (это просто промт-файлы). Точка входа для обнаружения —
раздел «Скиллы» в памяти проекта (MEMORY.md): реестр имён + правило
резолва.

## skills/PROJECT.md — нюансы проекта

Обязательный контекст для любого скилла перед вопросами. Формат —
короткие правила, не история (история — в MEMORY.md):

```markdown
# PROJECT — нюансы <проект> для скиллов

## Роли и права      # роли, матрица/уровни, кто владелец прав
## Персистентность   # персистентные моки, schemaVersion, инварианты слоёв
## Эталоны           # «где уже сделано»: ссылки на модули/компоненты
## Запреты           # прямые запреты (импорты, raw-значения, паттерны)
## Состояния         # конвенция §48 и pending-операций проекта
```

Правило пополнения: нюанс, повторившийся в двух фичах, — кандидат в
PROJECT.md (фиксируется скиллом feature в verify).

## Доработка и подъём

- **Правка в проектном слое** безопасна и дешева: оверрайд одного
  скилла или дополнение PROJECT.md. Так проект управляет скиллами
  внутри себя.
- **Подъём** (канонизация, как у компонентов): проектная правка,
  обобщившаяся до «полезно всем проектам на платформе», переносится
  в платформенный скилл `<skill>/…` (резолв — выше); канон —
  платформенная версия,
  проектные расхождения остаются в проектном слое. Фиксируется
  D-записью/коммитом в платформенном скилле.
- Новый скилл, родившийся из проекта, стартует проектным; после
  2–3 обкаток — подъём в платформу.
