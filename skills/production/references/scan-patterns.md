# Скан-паттерны (инвентарь хардкода)

Статический скан по src проекта (+ платформенные слои, если ядро
в монорепо). Каждый паттерн = категория + уровень по умолчанию;
уровень может уточняться правилами домена (checklist.md).

## Таблица паттернов

| Категория | Что ищем | Как | Уровень |
|---|---|---|---|
| API URL | захардкоженный baseUrl | `baseUrl:` в App.tsx / services-конфиге | 🔴 если не из env |
| Мок-токен | `getToken: () => "…"`, `token: "tok-…"` | grep `getToken`, `token:` | 🔴 |
| Демо-учётки | «любой пароль», `defaultEmail`, роль из префикса email | чтение auth-мока, grep `password` | 🔴 для прода |
| Секреты | `API_KEY`, `SECRET`, `PASSWORD =` | grep -i по src и .env* | 🔴 если найдены |
| Внешние URL | `https?://` в src (валидации w3.org — не в счёт) | grep; демо-медиа: picsum, pravatar, публичные PDF/DWG | 🟡 |
| Искусственные delay | `wait(N)`, `setTimeout` в мок-сервисах | grep | 🟡 |
| Сиды | `MOCK_*`, `*_SEED`, `SEEDS` | grep + чтение сервисов | 🟡 |
| LS/IDB ключи | `localStorage`, `indexedDB`, `<proj>:` | grep | 🟢 инвентарь (префикс — конвенция) |
| console.* | `console.log/warn/error` в src проекта | grep | 🟡 почистить |
| env-слой | `import.meta.env` | grep | инверсия: мало использования = 🟡 нет env-слоя |
| XSS-поверхность | `innerHTML`, `dangerouslySetInnerHTML`, `eval` | grep | 🔴 если есть |
| Сборка | sourcemap, base, минификация | чтение vite.config + dist | 🟡 sourcemap в проде |

## mockFlags-таблица (главная)

`App.tsx` services-конфиг — центр переключателей. Скан обязан выдать
таблицу по каждому сервису:

| Сервис | Активная стратегия | api-стратегия реализована? |
|---|---|---|
| feed | mock | да / `throw` («не подключён») |

`throw` в api-стратегии = «переключить нельзя» — отдельная графа и
автоматический 🔴 у домена transport.

## Процедура

1. Сначала mockFlags-таблица (структура уже есть в коде) — она каркас,
   остальное навешивается на неё.
2. Потом grep-паттерны по таблице выше; каждое попадание — с цитатой
   и `файл:строка`.
3. Пробег по сборке: vite.config (sourcemap/base), package.json
   скрипты (режимы), наличие `.env*`.
4. Модели имена (picsum/pravatar и т.п.) держать списком в скорборде —
   это и есть «демо-медиа», при переходе на прод заменяются на
   реальные источники.

Скан статический: запускается только сборка (verify), сеть не трогаем.
