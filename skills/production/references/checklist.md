# Скорборд: домены и критерии

Уровень пункта назначается правилом, не на глаз:

- 🔴 **блокер** — нельзя на прод;
- 🟡 **осознанный мок-этап** — допустимо только со ссылкой на решение
  (MEMORY / decisions / дока модуля); без ссылки пункт считается 🔴;
- 🟢 **готово**.

## Домены и правила

### transport
- mockFlags: все `true` → 🔴; смешанные → таблица по сервисам.
- api-стратегия `throw` («не подключён») → 🔴 у сервиса.
- `baseUrl` не из env → 🔴.
- HttpTransport + baseUrl из env + таймаут → 🟢.

### auth
- Пароль игнорируется (`_password`) / роль из префикса email → 🔴
  (мок-этап 🟡 — только с записанным решением).
- Токен-константа (`tok-mock`) в бандле → 🔴.
- `getToken` читает сессию → 🟢.
- Сессия в localStorage → 🟡 (риск фиксируется в security, компенсация
  — чистая XSS-поверхность).

### env
- Нет `.env.example` / нет режимов сборки → 🟡.
- Нет типизации ImportMetaEnv / fail-fast валидации → 🟡.
- Секрет в `VITE_*` → 🔴 (всё попадает в бандл).

### Данные и медиа
- Демо-медиа (picsum/pravatar/публичные PDF/DWG) в сидах → 🟡.
- PersistentMock вместо API → 🟡 (осознанно, schemaVersion-дисциплина
  соблюдена — 🟢 в своей части).

### Сборка
- Sourcemap в прод-артефакте → 🟡 (публикация исходников).
- base не параметризован при sub-path деплое → 🟡.
- typecheck / lint / build не чистые → 🔴.

### Ошибки
- errorBus + handlers + module ErrorBoundary подключены → 🟢.
- Прод-репортер отсутствует → 🟡 (точка роста, не блокер).

### Безопасность
По `references/security.md` — отдельная таблица рисков.

## Счёт и вердикт

- Счёт домена = количество 🔴/🟡/🟢 по пунктам; итог прогона:
  «N блокеров · M моков · K готово».
- Вердикт — три градации (полный мок без бэкенда — осознанный стенд,
  но не прод):
  - **«не к продоу»** — есть 🔴 без ссылки на решение;
  - **«стенд-этап (осознанный)»** — 🔴 нет, все 🟡 закрыты решениями,
    но transport полностью на моках: прод невозможен до подключения
    бэкенда;
  - **«к продоу»** — 🔴 нет, 🟡 закрыты решениями, transport
    переключаем (api-стратегии реализованы, не `throw`).
- Формула простая, интерпретация — за людьми (гейт скилла —
  содержательный).

## Формат docs/production.md

```markdown
# Production-скорборд — <проект>
Прогон: <date> · commit <sha> · вердикт: <к продоу / не к продову>

## Счёт
| Домен | 🔴 | 🟡 | 🟢 |
|---|---|---|---|

## Блокеры (🔴)
| Что | Где | Чем чинится | Кто решает |

## Осознанные моки (🟡)
| Что | Где | Решение (ссылка) |

## Diff с прошлым прогоном
улучшилось: … / деградировало: … / не изменилось: …

## Открытые вопросы
```

Снимок прогона (полная таблица скана) — копией в
`docs/production/runs/run-<date>.md`, append-only.
